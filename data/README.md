# Data

The dataset used in this project is the **CDC PLACES 2024 release** (GIS-friendly format, Census Tract level).

It is not included in this repository due to file size (~500MB+).

## Download

1. Go to: https://www.cdc.gov/places/index.html
2. Select **"Census Tract Data"** → **2024 release** → **GIS Friendly Format**
3. Download and place the CSV in the project root directory with this exact filename:

```
PLACES__Census_Tract_Data_(GIS_Friendly_Format),_2024_release_20251010.csv
```

## About the Data

- ~73,000 U.S. census tracts
- Model-based prevalence estimates for chronic diseases, preventive care, mental health, and social determinants
- Published by the CDC Division of Population Health
